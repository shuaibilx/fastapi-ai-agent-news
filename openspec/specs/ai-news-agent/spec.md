# ai-news-agent Specification

## Purpose

为已认证用户提供一个受控的新闻 Agent，使其能够根据自然语言意图组合新闻知识检索、新闻详情、个人收藏和浏览历史等只读能力，并返回可追溯且不跨越用户边界的回答。

## Requirements

### Requirement: 已认证的新闻 Agent 请求

系统 SHALL 提供 `POST /api/ai/agent` 接口，接受非空的用户消息和可选的 `conversationId`，并返回 Agent 的非流式最终回答。客户端 MUST NOT 需要或提供模型供应商凭据。系统 MUST 在调用模型或业务工具前按服务端敏感信息策略检查用户消息。

#### Scenario: 提交有效 Agent 消息

- **WHEN** 已认证用户提交非空且不包含被阻断敏感信息的消息
- **THEN** 系统执行 Agent 并返回最终回答和 `conversationId`

#### Scenario: 拒绝未认证请求

- **WHEN** 请求没有有效的 Bearer Token
- **THEN** 系统返回应用统一认证错误，且不会执行 Agent

#### Scenario: 拒绝空消息

- **WHEN** 已认证用户提交空消息或仅包含空白字符的消息
- **THEN** 系统返回校验错误，且不会调用模型或业务工具

#### Scenario: 阻断凭据型敏感输入

- **WHEN** 已认证用户消息包含被服务端策略阻断的 API Key、访问令牌或私钥等凭据型内容
- **THEN** 系统返回明确的安全校验错误，且不会调用模型、工具或持久化会话状态

### Requirement: Agent 只读工具选择

Agent SHALL 能够根据用户意图选择新闻知识检索、新闻详情、当前用户收藏列表和当前用户浏览历史工具。所有暴露给 Agent 的业务工具 MUST 为只读操作，系统 MUST NOT 在本能力中提供新增、更新、删除或清空数据的工具。

#### Scenario: 查询单篇新闻详情

- **WHEN** 用户明确要求查看某个新闻 ID 的详情
- **THEN** Agent 调用新闻详情工具，并基于该工具返回的数据作答

#### Scenario: 查询个人收藏

- **WHEN** 用户询问自己的收藏新闻
- **THEN** Agent 调用当前用户收藏列表工具并返回有界结果

#### Scenario: 查询个人浏览历史

- **WHEN** 用户询问自己的浏览记录
- **THEN** Agent 调用当前用户浏览历史工具并返回有界结果

#### Scenario: 查询新闻知识

- **WHEN** 用户提出需要从新闻库查找资料的问题
- **THEN** Agent 调用新闻知识检索工具，并基于检索结果作答

#### Scenario: 无需工具即可回答

- **WHEN** 用户消息不需要访问新闻数据或个人数据即可安全回答
- **THEN** Agent 可以不调用业务工具直接返回回答

### Requirement: 复用可替换的新闻检索能力

新闻知识工具 SHALL 复用现有新闻检索抽象并返回有界的新闻片段与引用元数据，而 MUST NOT 通过嵌套调用完整新闻 QA 生成流程来产生工具结果。现有 `POST /api/ai/qa` 接口 SHALL 继续独立可用且行为保持不变。

#### Scenario: Agent 检索到新闻资料

- **WHEN** 新闻知识工具找到与问题相关的新闻
- **THEN** 工具向 Agent 提供有界上下文，并提供由系统生成的新闻 ID、标题和摘录元数据

#### Scenario: Agent 检索不到新闻资料

- **WHEN** 新闻知识工具没有找到相关新闻
- **THEN** Agent 明确说明没有足够新闻资料，且不伪造引用

#### Scenario: 直接 QA 继续工作

- **WHEN** 客户端调用现有 `POST /api/ai/qa`
- **THEN** 系统继续按照 `ai-news-qa` 契约执行固定的检索增强问答

### Requirement: 认证用户上下文隔离

系统 SHALL 从服务端认证上下文获得可信用户身份，并将其用于收藏和浏览历史工具。客户端和模型 MUST NOT 能通过工具参数指定或覆盖 `user_id`。

#### Scenario: 工具访问当前用户数据

- **WHEN** 已认证用户触发收藏或浏览历史工具
- **THEN** 工具只查询该认证用户拥有的数据

#### Scenario: 模型尝试指定其他用户

- **WHEN** 用户消息要求 Agent 查看其他用户的收藏或浏览历史
- **THEN** Agent 不得跨用户查询，并返回拒绝或仅返回当前用户范围内的信息

### Requirement: 可追溯的 Agent 响应

成功响应 SHALL 包含最终回答、`conversationId`、去重后的新闻引用、已执行工具的安全摘要和记忆状态。引用 MUST 来源于工具返回的可信元数据，而不是由模型自由生成；工具摘要 MUST NOT 暴露供应商凭据、数据库连接信息、其他用户数据或可被当前策略检测的敏感信息。系统 SHALL 在返回最终回答、引用和工具摘要前按服务端策略处理可检测敏感信息。

#### Scenario: 回答使用新闻来源

- **WHEN** Agent 基于新闻知识检索或新闻详情作答
- **THEN** 响应包含支持回答的新闻 ID、标题和可用摘录

#### Scenario: 回答调用多个工具

- **WHEN** Agent 在一次请求中调用多个工具
- **THEN** 响应列出各工具名称和执行状态，并对重复新闻引用进行去重

#### Scenario: 回答未调用新闻工具

- **WHEN** Agent 未使用任何带新闻来源的工具
- **THEN** 响应返回空引用列表，且不得生成虚构引用

#### Scenario: 工具结果包含个人信息

- **WHEN** 业务工具结果或模型最终回答包含被配置为脱敏的个人信息
- **THEN** 发送给模型的工具结果和返回给客户端的回答、引用及工具摘要均使用脱敏后的值

#### Scenario: 工具结果包含凭据型敏感信息

- **WHEN** 业务工具结果包含被配置为阻断的凭据型敏感信息
- **THEN** 系统不得将该原始内容提供给模型或客户端，并返回明确的安全错误或安全的工具失败摘要

### Requirement: Agent 故障与执行边界

系统 SHALL 对模型调用、工具结果大小和 Agent 执行轮次设置服务端限制。如果模型供应商失败、Agent 超出执行限制或核心工具执行失败，系统 SHALL 返回明确且稳定的错误语义，而 MUST NOT 返回未完成或无来源的伪造结果。

#### Scenario: 模型供应商不可用

- **WHEN** Agent 执行期间模型供应商失败或超时
- **THEN** 系统返回服务不可用响应并记录可诊断错误

#### Scenario: Agent 超出执行限制

- **WHEN** Agent 达到服务端允许的最大工具调用或推理轮次
- **THEN** 系统终止本次执行并返回明确错误，且不继续无限循环

#### Scenario: 工具返回内容过大

- **WHEN** 业务工具原始结果超过配置的上下文预算
- **THEN** 系统在交给模型前裁剪或压缩结果，同时保留必要标识与来源元数据

### Requirement: 服务端可配置的敏感信息策略

系统 SHALL 仅从服务端配置加载敏感信息检测类别、处理策略和自定义检测规则。浏览器 MUST NOT 能请求关闭、替换或放宽敏感信息过滤策略，也不得接收检测规则或供应商凭据。

#### Scenario: 浏览器调用 Agent 接口

- **WHEN** 前端发送 Agent 消息或展示 Agent 结果
- **THEN** 请求与响应不包含敏感信息检测规则、模型供应商凭据或绕过过滤的客户端开关

#### Scenario: 服务端调整过滤策略

- **WHEN** 服务端部署修改敏感信息检测类别或处理策略
- **THEN** 后续 Agent 请求按更新后的服务端策略执行，无需客户端变更
